# Launch playbook — first city (Bengaluru pilot)

> These are plans, not accomplishments. Every number below is a target to verify, not a claim.

## Positioning (30-second pitch)

> “Your group chat has three event links and no decision. CommunityConnect turns those links into one plan: everyone marks can/maybe/cannot, clashes show up automatically, and the circle confirms a single event — with a buddy if you want company. It’s free.”

## The growth loop (product-built, not gimmick)

1. A useful plan → member shares their **invite link** → friend joins deliberately → **both get +75 XP and boosts** → group completes a decision → member starts the next plan.
2. Helpful curation → +10 XP per approved event post → better local inventory → more circles.
3. Good event → takeaway note → source-linked discovery → newcomers start plans.
4. QR networking card → used at real events → scan → profile → connection → repeat attendance.

Referral mechanics implemented: once-per-invitee bonuses, 14-day referrer boost, 7-day welcome boost, Connector badge. Referral conversion is *measured* (invitations sent × accepted), never assumed viral.

## Week 1 — Seed (goal: 15 interviews, 30 events, 5 circles)
- Interview 10–15 attendees/organizers (campus clubs, meetup organizers, coworking spaces) about planning friction. Ask about the *last* event that fell apart.
- Post 25–30 accurate, source-linked events (founder + 2 volunteers). Zero invented listings.
- Create 5 real circles (friends/colleagues) and run one real Decision Room each.
- Print QR flyers (repo landing art + referral code) for 3 venues — **with organizer permission**.

## Week 2 — Decide together (goal: 10 completed decisions)
- Watch where voters hesitate; fix copy, not just pixels.
- Verify event freshness (source links still correct).
- Handle every report within 24h; publish nothing that violates conduct.

## Week 3 — Company & follow-up (goal: buddy acceptance ≥ 40%)
- Push the buddy board for newcomers (“nobody walks in alone”).
- Test the networking card at 2 events; collect scan→connection conversion anecdotes.
- One organizer feature request → backlog (don’t build ad hoc).

## Week 4 — Review (decision gate)
- Retention (week-2 return), completed plans, moderation load, willingness-to-pay interviews (₹99 Pro hypothesis).
- Expand / narrow / pivot per data. Update this file with real numbers.

## Guardrails (never optimize past these)
- Reports per 100 active users; spam prevalence (sampled review); unwanted-contact reports; deletion requests.
- Never: scraped attendee lists, unpromoted mass messages, fake activity in production, dark-pattern invite pressure.
- Analytics stay aggregate and privacy-safe; no reading private messages.

## Ambassador kit (volunteer checklist)
- Attend with permission, demo a Decision Room in <60s, hand out the QR card, invite interested people to a *relevant* circle, log 3 pieces of feedback per event.

## Assets in-product
Landing hero + steps (shareable), referral share card, networking card print CSS, pricing interest form, conduct/privacy pages for organizer diligence.
